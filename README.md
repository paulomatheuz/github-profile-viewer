# GitHub Profile Viewer

Projeto em Python para praticar a criação de um visualizador de perfis do GitHub.

No estágio atual, o programa solicita um nome de usuário e valida se a entrada não está vazia.

## Como executar

Com o Python instalado, execute no terminal dentro da pasta do projeto:

```bash
python main.py
```
